# Эмулятор командной строки UNIX (Вариант 30)

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом (tkinter),
выполненный в рамках дисциплины «Конфигурационное управление».

**Группа:** ИКБО-64-25, РТУ МИРЭА, 3 семестр 2026/2027.

## Этап 1. REPL

- GUI-приложение: поле вывода и строка ввода с приглашением.
- Заголовок окна содержит имя VFS: `Эмулятор - [имя]`.
- Парсер разделяет ввод по пробелам и раскрывает переменные окружения
  (`$HOME`, `${HOME}`).
- Ошибки: неизвестная команда, неверные аргументы.
- Команды: `ls`, `cd` (заглушки), `exit`.

## Сборка и тесты

```
make test
make run
```
