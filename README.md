# Эмулятор командной строки UNIX (Вариант 30)

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом (tkinter),
выполненный в рамках дисциплины «Конфигурационное управление».

**Группа:** ИКБО-64-25, РТУ МИРЭА, 3 семестр 2026/2027.

## Этап 1. REPL

- GUI-приложение: поле вывода и строка ввода с приглашением.
- Заголовок окна содержит имя VFS: `Эмулятор - [имя]`.
- Парсер разделяет ввод по пробелам и раскрывает переменные окружения
  (`$HOME`, `${HOME}`).
- Ошибки: неизвестная команда, неверные аргументы.
- Команды: `ls`, `cd` (заглушки), `exit`.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр | Описание |
| --- | --- |
| `--vfs <путь>` | путь к физическому расположению VFS |
| `--script <путь>` | путь к стартовому скрипту |
| `--headless` | без окна: весь вывод в stdout (для автотестов) |

- При запуске выводятся отладочные строки `[debug] ключ = значение`.
- Стартовый скрипт выполняется последовательно, на экран выводятся и ввод
  (с приглашением), и вывод. Пустые строки и строки, начинающиеся с `#`,
  пропускаются. **При первой ошибке скрипт останавливается**,
  выводится номер строки.
- Команда `conf-dump` печатает параметры в формате `ключ=значение`.
- Скрипты реальной ОС: `tests/os/stage2.sh`.

## Этап 3. VFS

- Источник VFS — **директория на диске** (`--vfs <папка>`). Она целиком
  читается в память (в том числе бинарные файлы, как `bytes`), после этого
  все операции идут только в памяти, диск не изменяется.
- Имя VFS — имя папки; оно показывается в заголовке окна и в приглашении
  (`имя:/путь$`). Без `--vfs` создаётся VFS по умолчанию в памяти.
- Ошибки загрузки (папка не найдена, путь — не папка) выводятся в окно,
  эмулятор продолжает работу с VFS по умолчанию.
- Если в корне VFS есть файл `motd`, его текст выводится при старте.
- Примеры VFS: `examples/vfs/minimal`, `examples/vfs/multi`,
  `examples/vfs/deep` (4 уровня вложенности).
- Скрипты: `tests/os/stage3.sh`, `examples/scripts/stage3.emu`.

## Этап 4. Основные команды

- `ls [-l] [путь]` — содержимое папки (или файла) VFS; каталоги помечаются
  `/`, с `-l` выводятся права, размер и имя.
- `cd [путь]` — смена папки: абсолютные и относительные пути, `.`, `..`;
  `cd` без аргументов — в корень. Текущий путь виден в приглашении.
- `clear` — очистить экран.
- `echo [текст...]` — вывести аргументы (переменные окружения раскрываются).
- `who` — пользователь, терминал, время начала сеанса.
- Скрипты: `tests/os/stage4.sh`, `examples/scripts/stage4.emu`.

## Этап 5. Дополнительные команды

- `rm [-r] путь...` — удалить файл(ы); папки только с `-r`. Текущую папку
  и её родителей удалить нельзя.
- `mv источник приёмник` — переименовать/переместить файл или папку;
  если приёмник — существующая папка, объект кладётся внутрь неё.
  Нельзя перенести папку в саму себя.
- Все изменения — только в памяти, файлы на диске не затрагиваются.
- Скрипты: `tests/os/stage5.sh`, `examples/scripts/stage5.emu`,
  `examples/scripts/stage5_deep.emu`.
