# Эмулятор командной строки UNIX (Вариант 30)

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом (tkinter),
выполненный в рамках дисциплины «Конфигурационное управление».

**Группа:** ИКБО-64-25, РТУ МИРЭА, 3 семестр 2026/2027.

## Этап 1. REPL

- GUI-приложение: поле вывода и строка ввода с приглашением.
- Заголовок окна содержит имя VFS: `Эмулятор - [имя]`.
- Парсер разделяет ввод по пробелам и раскрывает переменные окружения
  (`$HOME`, `${HOME}`).
- Ошибки: неизвестная команда, неверные аргументы.
- Команды: `ls`, `cd` (заглушки), `exit`.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр | Описание |
| --- | --- |
| `--vfs <путь>` | путь к физическому расположению VFS |
| `--script <путь>` | путь к стартовому скрипту |
| `--headless` | без окна: весь вывод в stdout (для автотестов) |

- При запуске выводятся отладочные строки `[debug] ключ = значение`.
- Стартовый скрипт выполняется последовательно, на экран выводятся и ввод
  (с приглашением), и вывод. Пустые строки и строки, начинающиеся с `#`,
  пропускаются. **При первой ошибке скрипт останавливается**,
  выводится номер строки.
- Команда `conf-dump` печатает параметры в формате `ключ=значение`.
- Скрипты реальной ОС: `tests/os/stage2.sh`.
